## Git Commands Reference

### Pushing to Repositories

**Push to original repository:**
```bash
git push origin main
```

**Push to your new repository (Rhyme's):**
```bash
git push rhyme main
```

**Push to both repositories at once:**
```bash
git push origin main && git push rhyme main
```

### Viewing Remotes
```bash
git remote -v
```

### Removing a Remote
```bash
git remote remove <remote-name>
```

### Adding a New Remote
```bash
git remote add <name> <url>
```
